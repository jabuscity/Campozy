# CAMPOZY DESIGN SYSTEM

## Status
Visual design authority.

## Brand Feel
Campozy should feel:
- trustworthy
- calm
- practical
- human
- student-centered
- transparent

## Color System
Primary: Campozy Blue `#1D4ED8`  
Secondary: Campozy Gold `#F59E0B`  
Success: `#16A34A`  
Warning: `#F97316`  
Danger: `#DC2626`

Neutral scale:
- 900 `#111827`
- 800 `#1F2937`
- 700 `#374151`
- 600 `#4B5563`
- 500 `#6B7280`
- 400 `#9CA3AF`
- 300 `#D1D5DB`
- 200 `#E5E7EB`
- 100 `#F3F4F6`
- 50 `#F9FAFB`

## Layout
- 8-point spacing system
- 4-column mobile grid
- 8-column tablet grid
- 12-column desktop grid
- max width 1280px
- reading width 720px

## Radius
- 8px
- 12px
- 16px
- 24px
- 999px for pills/search

## Buttons
- Primary
- Secondary
- Ghost
- Danger

## Core Components
- Search bar
- Property card
- Campozy score component
- Trust badges
- Founder badges
- Review cards
- Opportunity cards
- Discussion cards

## Campozy Score Visual Logic
- 90+ Green
- 75–89 Blue
- 60–74 Orange
- Below 60 Red

## Founder Badge Philosophy
Founder badges should feel earned, local, and meaningful:
- Campus Founder
- Country Founder
- Global Pioneer

## Motion
Minimal, fast, purposeful.

## Accessibility
Components must be reusable, responsive, accessible, and trustworthy.
