# CAMPOZY UI/UX PHILOSOPHY

## Status
Design constitution.

## Core Philosophy
Campozy is a Student Decision Platform, not a generic property marketplace.

## Emotional Objectives
A student should feel:
- safe
- understood
- supported
- informed
- confident
- empowered

Never:
- overwhelmed
- manipulated
- pressured
- confused

## Personality
Campozy should feel:
- helpful
- honest
- calm
- practical
- knowledgeable
- encouraging
- trustworthy

## Design Principles
- Trust before beauty
- Utility before decoration
- Clarity before density
- Progressive disclosure
- Every visit must produce value

## Trust-First Interface Design
Trust signals should be visible on:
- property pages
- owner profiles
- reviews
- opportunities
- businesses

## Explainability
Never present intelligence without explanation.

## Onboarding Philosophy
Progressive onboarding, not interrogation.

## Gamification Philosophy
Reward contribution and leadership, not addiction.

Allowed:
- badges
- founder recognition
- contribution levels
- milestones

## Founder Experience
Founders should feel special because they helped build the ecosystem, not because they paid.

## Mobile Philosophy
Mobile first. Desktop follows.

## Search Philosophy
One search system should reach housing, campuses, universities, discussions, opportunities, and businesses.

## Privacy Philosophy
Users should understand what is collected and why.

## Accessibility
Readable typography, keyboard access, accessible forms, sufficient contrast.

## North Star
Confidence is the product. Everything else is the interface.
